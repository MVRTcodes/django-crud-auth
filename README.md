Este proyecto está desarrollado con Django y demuestra la implementación de funcionalidades esenciales del framework. Está diseñado para gestionar usuarios y datos mediante un sistema de autenticación que incluye registro y login. Además, permite realizar operaciones CRUD sobre los registros, manteniendo una estructura organizada y segura. Utiliza el patrón Modelo-Vista-Plantilla de Django, asegurando una separación clara entre la lógica de negocio y la presentación de datos.

This project is developed with Django and demonstrates the implementation of essential framework functionalities. It is designed to manage users and data through an authentication system that includes registration and login. Additionally, it allows performing CRUD operations on records, maintaining an organized and secure structure. It uses Django's Model-View-Template pattern, ensuring a clear separation between business logic and data presentation.

Funcionalidades / Features

- Autenticación de usuarios con registro e inicio de sesión / User Authentication with Registration and Login
- Operaciones CRUD / CRUD Data Management 
- Modelo-Vista-Plantilla / Model-View-Template
- Ruteo y Navegación / Routing and Navigation
- Seguridad y Autorización / Security and Authorization
- Validación de Formularios / Form Validation
